# QGIS Plugins

## НСПД

`rosreestr-search-qgis-plugin` используется для кадастрового контекста. Water Regime GIS отдельно делает `GetFeatureInfo` по выбранной точке. WMS остается визуальным слоем и не заменяет расчетную векторную границу.

Установка:

```bash
python3 scripts/install_nspd_plugin.py
```

## Observearth

Установлен Observearth 1.0.2. Плагин используется для интерактивного поиска и визуальной проверки спутниковых сцен. Постоянные GeoTIFF создает собственный GDAL-пайплайн.

Проверка на поле `SP:4.17` показала максимальное расхождение NDMI `7.45e-08` между движком Observearth и проектным расчетом на одинаковых каналах.

## Isoliner

Установлен Isoliner 5.6.21. Используются стабильные Processing ID:

- `isoliner:raster_to_isolines` — линии и зоны по индексному растру;
- `isoliner:kriging2d` — интерполяция реальных точечных измерений.

Проверка NDMI на `SP:4.17` создала 187 линий и 197 полигональных зон. Кригинг без реальных измерений не выполняется.
