# Architecture

## Общий принцип

Проект строится вокруг пользовательской панели как основного интерфейса и QGIS/PyQGIS как скрытого геодвижка. Пользователь не должен работать в интерфейсе QGIS.

## Слои архитектуры

1. **Data layer** — локальные файлы GeoTIFF, GeoPackage, CSV, Parquet; в будущем PostGIS.
2. **Processing layer** — Python, PyQGIS, GDAL/OGR, QGIS Processing, Rasterio/GeoPandas при необходимости.
3. **Analysis layer** — расчет спектральных индексов, рельефных производных и сравнительных таблиц.
4. **Application layer** — desktop-интерфейс для Windows/macOS, запуск проверок, установки модулей и скрытых QGIS-скриптов.
5. **Visualization layer** — preview, карты и отчеты, возвращаемые в панель; QGIS-проекты остаются внутренними артефактами.
6. **Knowledge layer** — `docs/wiki/` как человеко- и AI-читаемая документация.

## Текущая структура

```text
src/                  # будущий Python-пакет проекта
scripts/              # запускаемые скрипты обработки
scripts/qgis/         # скрипты, рассчитанные на запуск в QGIS Python
notebooks/            # исследовательские ноутбуки
configs/              # конфигурации пайплайнов
data/aoi/             # границы областей интереса
data/raw/             # сырые данные
data/interim/         # промежуточные результаты
data/processed/       # обработанные результаты
outputs/maps/         # карты и QGIS-выгрузки
outputs/reports/      # отчеты
outputs/rasters/      # итоговые растры
docs/wiki/            # проектная wiki
```

## Минимальная реализация первого этапа

- `pyproject.toml` фиксирует имя проекта и минимальную версию Python.
- `configs/project.example.json` хранит базовые пути, источники данных, список индексов и DEM-продуктов.
- `src/water_regime_gis/project.py` содержит минимальные функции для поиска корня проекта, чтения JSON-конфига и проверки структуры.
- `scripts/check_project.py` является первым исполняемым скриптом проекта.
- `src/water_regime_gis/webapp.py` является текущей первой версией интерфейса.
- `scripts/run_app.py` запускает локальное веб-приложение из рабочей копии.
- `scripts/qgis/check_qgis_context.py` проверяет запуск PyQGIS через QGIS Python.
- `scripts/install_nspd_plugin.py` автоматически устанавливает кадастровый QGIS-плагин НСПД в профиль пользователя.
- `scripts/qgis/create_demo_project.py` скрыто создает QGIS-проект `outputs/maps/water_regime_gis.qgs` и preview для панели.

## Desktop-приложение

Целевая форма продукта — приложение для Windows и macOS. Текущая первая версия использует локальный веб-интерфейс на стандартной библиотеке Python, чтобы не добавлять внешние GUI-зависимости и избежать лицензионной сложности на старте.

Пробный `tkinter`-модуль `src/water_regime_gis/app.py` оставлен как черновик, но основной запуск идет через `src/water_regime_gis/webapp.py`.

## PostGIS

PostGIS планируется как будущий слой хранения и пространственных запросов. На первом этапе проект должен работать без базы данных, используя файловые форматы.

## QGIS

QGIS используется как скрытый исполняемый слой для:

- запуска PyQGIS/Processing-алгоритмов;
- создания внутренних QGIS-проектов;
- подготовки preview, карт и промежуточных геоданных;
- работы с QGIS-плагинами, если их можно установить и запускать автоматически.

Пользовательские проверки и результаты должны возвращаться в панель.

## Автоматизация

Автоматизированные пайплайны должны быть доступны как Python-скрипты в `scripts/` и переиспользуемый код в `src/`.
