# Glossary

## AOI

Area of Interest, область интереса для анализа.

## CRS

Coordinate Reference System, система координат.

## DEM

Digital Elevation Model, цифровая модель рельефа.

## NDVI

Normalized Difference Vegetation Index, индекс растительности.

## NDMI

Normalized Difference Moisture Index, индекс влажности растительности.

## NDWI

Normalized Difference Water Index, индекс воды или влажности. Конкретная формула должна быть явно зафиксирована в пайплайне.

## MNDWI

Modified Normalized Difference Water Index, модифицированный индекс воды с использованием SWIR.

## SAVI

Soil Adjusted Vegetation Index, индекс растительности с поправкой на влияние почвы.

## NDRE

Normalized Difference Red Edge Index, индекс по red edge каналу, применимый прежде всего к Sentinel-2.

## GeoTIFF

Растровый геоформат для хранения пространственно привязанных данных.

## GeoPackage

Файловый контейнер SQLite для векторных и растровых геоданных.

## PostGIS

Расширение PostgreSQL для пространственных данных.

## PyQGIS

Python API QGIS.
