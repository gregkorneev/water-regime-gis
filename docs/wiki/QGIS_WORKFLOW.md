# QGIS Workflow

## Установка

```bash
cd /Users/korneev/Desktop/water-regime-gis
python3 scripts/install_qgis_plugin.py
python3 scripts/install_nspd_plugin.py
```

Перезапустить QGIS и включить Water Regime GIS, Observearth, Isoliner и модуль НСПД в менеджере модулей.

## Основной сценарий

1. Открыть dock-панель `Water Regime GIS`.
2. `Проверить среду` — проверить QGIS, плагины и рабочие каталоги.
3. `Взять точку с карты` — кликнуть внутри поля. Создаются точка и fallback-буфер 500 м.
4. `Уточнить границу` — попытаться заменить буфер подходящим кадастровым полигоном НСПД.
5. `Рассчитать индексы` — найти наименее облачную Sentinel-2 L2A сцену за последние 60 дней, обрезать каналы, рассчитать шесть индексов и сохранить `outputs/reports/latest_metrics.json`.
6. Выбрать нужный индексный растр в слоях.
7. `Построить изолинии` — открыть Isoliner с начальными уровнями NDMI.
8. `Собрать проект/слои` — загрузить отсутствующие AOI/растры и сохранить текущий проект.

## Дополнительные команды

`Открыть Observearth` открывает интерактивный STAC-интерфейс. Для ограничения поиска сначала выделяется одно поле; без выделения Observearth использует весь полигональный слой.

`Кригинг измерений` принимает только активный точечный слой минимум с тремя объектами и числовым полем. Плагин подставляет первое числовое поле, остальные параметры остаются под контролем пользователя в Processing-диалоге.

`График по полю` загружает SP-слои только для полей с поставленными суточными
рядами КОРНИКС, кроме намеренно исключённого SP 7.3. Двойной щелчок открывает
три синхронизированные панели: Sentinel-2 индексы и FCOVER, модельные ряды
КОРНИКС (в том числе ожидаемый FCover) и относительный индикатор Sentinel-1
по VV. Последний имеет общую шкалу 0.153527–0.367581 и не является процентной
влажностью почвы. Фильтр применяется только к отображению в QGIS и не меняет
исходные границы или данные.

`Средний график` строит те же три панели без выбора контура. При каждом
нажатии он перечитывает текущие отчёты Sentinel-2/Sentinel-1 и файлы КОРНИКС,
сводит повторные наблюдения одного поля за дату медианой и затем рассчитывает
простое среднее между всеми доступными полями КОРНИКС. SP 7.3 исключается.

KAA-границы и группы снимков в проекте выключены. Снимки сохранены в
`outputs/imagery/kaa/`, но больше не загружаются инструментом графика.

## CRS

Точка и GeoJSON хранятся в `EPSG:4326`. Для каждого выбранного поля автоматически выбирается локальная UTM-зона и записывается в `analysis_crs`. Все метрические операции и спутниковые растры используют эту CRS.

## Ограничения

- НСПД может быть недоступна или вернуть слишком крупный кадастровый объект; тогда сохраняется fallback-буфер.
- Визуальный WMS НСПД добавляется его собственным QGIS-плагином и не записывается Water Regime GIS автоматически.
- Для кригинга пока нет реальных наземных измерений.
- DEM-анализ и временные ряды не реализованы.
