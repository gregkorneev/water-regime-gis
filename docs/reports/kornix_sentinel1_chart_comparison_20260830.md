# Сопоставление влажности КОРНИКС и Sentinel-1 на графиках SP

## Статус

Документ фиксирует результаты интерактивного анализа рядов в QGIS по состоянию
на 2026-08-30. Это описание согласованности модельного ряда КОРНИКС и
нормированного сигнала Sentinel-1, а не калибровка по независимым полевым
измерениям влажности.

## Данные и выборка

- Источник КОРНИКС: метод `ivanov_n4l_meteo_soil`, объемная влажность слоя
  0–10 см (`soil_surface_0_10_theta`).
- Источник Sentinel-1: зональное среднее VV в dB из
  `outputs/reports/sentinel1_zonal_means.csv`.
- Сопоставление выполняется только по точным общим датам поля.
- Поле `SP 7.3` исключено из интерактивного анализа по решению пользователя.
- В итоговой проверке использовано 36 полей и 2 118 пар «поле–дата».

## Текущая нормировка графика Sentinel-1

Каждый сезонный ряд VV сначала переводится внутри поля в диапазон 0–1 по его
минимуму и максимуму. Затем для всех полей применяется единая шкала:

\[
0 \rightarrow 0.153527, \qquad 1 \rightarrow 0.367581.
\]

Эта шкала является центром индивидуальных шкал, которые ранее подбирались для
согласования среднего и дисперсии с КОРНИКС. Она выбрана для сопоставимости
графиков между полями, а не для принудительного совпадения рядов каждого поля.
Монотонная линейная нормировка не изменяет корреляцию и направление тренда
внутри поля.

## Корреляция

| Показатель | Значение |
| --- | ---: |
| Pooled Pearson r | 0.274362 |
| Pooled Spearman ρ | 0.277281 |
| Медиана Pearson r внутри поля | 0.275619 |
| Среднее Pearson r внутри поля | 0.290357 |
| Поля с Pearson r ≥ 0.5 | 5 из 36 |
| Поля с отрицательным Pearson r | 3 из 36 |

Pooled p-value Pearson равен `6.92×10⁻³⁸`, однако это следствие большого
числа зависимых по времени наблюдений и не характеризует практическую силу
связи. Практически важен сам коэффициент: связь слабая–умеренная. Простое
линейное соответствие имеет \(r^2 \approx 0.075\), то есть объясняет лишь
около 7.5% pooled-вариации.

## Тренды

Для каждого поля на общих датах рассчитан линейный наклон ряда по времени.

| Показатель | Значение |
| --- | ---: |
| Поля с одинаковым направлением линейного тренда | 11 из 36 (30.6%) |
| Поля с положительным трендом КОРНИКС | 6 |
| Поля с положительным трендом Sentinel-1 | 27 |
| Pearson-корреляция наклонов между полями | -0.157733 |
| Spearman-корреляция наклонов между полями | -0.049936 |

Систематического совпадения трендов нет: направления линейного тренда
противоположны в 25 из 36 полей. Поэтому нельзя утверждать, что Sentinel-1 и
КОРНИКС показывают одинаковую сезонную динамику влажности.

## Сопоставление распределений и калибровок

На предыдущем этапе для каждого поля подбиралась отдельная линейная шкала,
совпадающая с КОРНИКС по среднему и дисперсии. Это технически выравнивает два
момента распределения, но не доказывает совпадение формы ряда, тренда или
физической природы величин. При проверке распределений после выравнивания
среднего pooled KS-тест и тест Brown–Forsythe отвергали одинаковость
распределений и дисперсий; следовательно, совпадение среднего не следует
трактовать как принадлежность одной генеральной совокупности.

В качестве возможного упрощения были рассчитаны две групповые шкалы, лучше
приближающие средние и дисперсии индивидуальных калибровок:

| Группа | Нормировка |
| --- | --- |
| 1 | `0 → 0.140578`, `1 → 0.348688` |
| 2 | `0 → 0.169712`, `1 → 0.391197` |

Они не применяются в плагине: активна единая шкала, указанная выше.

## Возможность воспроизведения КОРНИКС

По одному Sentinel-1 надёжно воспроизводить расчетную влагу КОРНИКС нельзя.
Независимая field-holdout проверка, описанная в
`docs/reports/kornix_sentinel1_reconstruction.md`, дала для признаков только
Sentinel-1 `R²=0.181`. При добавлении осадков и поливов `R²` повышался с 0.562
до 0.579, то есть основной вклад давала информация о водном поступлении, а
радар добавлял небольшой положительный вклад.

## Итоговые выводы

1. Sentinel-1 VV является дополнительным относительным индикатором состояния
   поля, но не заменяет модель КОРНИКС или измерение влажности почвы.
2. Связь с влагой КОРНИКС слабая–умеренная; называть ее сильной нельзя.
3. Одинаковые тренды не подтверждены.
4. Единая нормировка нужна для удобного сопоставления графиков, но не является
   физической калибровкой влажности.
5. Для проверки физической точности нужны синхронные независимые полевые
   измерения влажности, а также проверка на других сезонах и культурах.
