# water-regime-gis

QGIS-ориентированная информационная система для сравнительного анализа спутниковых, рельефных, расчетных и в дальнейшем наземных данных водного режима сельскохозяйственных земель.

## Цель

Создать воспроизводимый рабочий контур для анализа водного режима агроландшафтов на основе:

- спутниковых данных Sentinel-2 и Landsat;
- цифровых моделей рельефа;
- спектральных индексов растительности и влажности;
- расчетных топографических характеристик;
- результатов, пригодных для визуализации в QGIS и дальнейшего анализа.

На первом этапе наземные измерения не используются. Архитектура сразу предусматривает их последующее добавление.

## Рабочая гипотеза

Пространственная неоднородность водного режима сельскохозяйственных земель может быть описана через совместный анализ:

- спектральных индексов NDVI, NDMI, NDWI, MNDWI, SAVI, NDRE;
- рельефных факторов: высоты, уклона, экспозиции, аккумуляции стока, водосборов;
- временной динамики спутниковых наблюдений;
- расчетных зон переувлажнения, дренированности и потенциального водного стресса.

В дальнейшем эта расчетная картина будет сопоставляться с наземными измерениями и геостатистическими моделями.

## Этапы проекта

1. Базовая структура репозитория, wiki и правила работы.
2. Подготовка AOI, соглашений по данным и конфигурациям.
3. Загрузка или подключение спутниковых сцен Sentinel-2 / Landsat.
4. Расчет спектральных индексов и сохранение результатов в GeoTIFF.
5. Обработка DEM: уклон, экспозиция, аккумуляция стока, водосборы.
6. Сбор расчетных слоев в GeoPackage, CSV или Parquet.
7. Настройка QGIS-проекта и PyQGIS/Processing-пайплайнов.
8. Подготовка архитектуры для PostGIS.
9. Добавление наземных измерений, валидации и геостатистики.

## Базовый стек

- macOS как основная рабочая среда.
- Windows как целевая платформа приложения.
- QGIS, PyQGIS и Processing Toolbox.
- Локальный веб-интерфейс на стандартной библиотеке Python для первой версии приложения.
- GDAL/OGR, Rasterio, GeoPandas, Shapely, PyProj.
- NumPy, Pandas, PyArrow.
- GeoTIFF для растровых результатов.
- GeoPackage для векторных слоев и промежуточных результатов.
- CSV/Parquet для табличных расчетов.
- PostGIS как будущий слой хранения и пространственных запросов.

## Первый запуск

Проверить базовую структуру проекта:

```bash
python3 scripts/check_project.py
```

Скрипт читает `configs/project.example.json` и проверяет наличие обязательных каталогов. Сложная геообработка на первом этапе не выполняется.

Проверить тестовый AOI:

```bash
python3 scripts/check_aoi.py --write-normalized
```

Скрипт проверяет GeoJSON, bbox, тип геометрии, замкнутость полигона, примерную площадь и при флаге `--write-normalized` создает рабочую копию в `data/interim/`.

Запустить первую версию приложения:

```bash
python3 scripts/run_app.py
```

Приложение откроется в браузере по локальному адресу `http://127.0.0.1:8765`. Пользователь работает только в этой панели: выбирает поле на карте и запускает подготовку результата. QGIS используется как скрытый геодвижок.
Пользователь выбирает рабочее поле точкой на карте. Выбранная точка передается во внутренний PyQGIS-скрипт, который создает локальные слои `data/aoi/selected_field_point.geojson` и `data/aoi/selected_field_area.geojson`; эти файлы не публикуются в git.

На macOS приложение автоматически пробует найти QGIS wrapper:

```text
/Applications/QGIS.app/Contents/MacOS/python
```

Демонстрационный сценарий:

1. Запустить приложение.
2. Выбрать точку поля на карте и нажать `Сохранить выбранное поле`.
3. Нажать `Проверить систему`.
4. Нажать `Подготовить результат`.

После этого панель покажет preview результата. QGIS-проект `outputs/maps/water_regime_gis.qgs` создается скрыто, без ручного открытия QGIS пользователем.
