# Agent Context

## Поддержка репозитория

- Основной интерфейс — QGIS-плагин `Water Regime GIS`; QGIS Python обязателен
  для тестов и скриптов с GDAL/PyQGIS. Полный набор тестов запускается командой
  `/Applications/QGIS.app/Contents/MacOS/python -m unittest discover -s tests -v`.
- Служебные файлы (`__pycache__/`, `*.pyc`, `.DS_Store`, `tmp/`) не
  версионируются. Не удалять геоданные, растры, результаты или QGIS-проекты без
  отдельного запроса.
- README — только установка, рабочий сценарий и ключевые команды. Детали
  архитектуры, данных и методики поддерживаются в `docs/wiki/`.

## Текущее состояние

- Подтверждающий первый эксперимент выполняется на 36 полях SP: `SP 7.3`
  исключено из всех аналитических выборок, но исходные данные не удаляются.
  `scripts/analysis/run_s1_s2_surface_validation.py` фиксирует вариант КОРНИКС
  65 см и VV Sentinel-1 в dB как основной показатель, создаёт шесть фолдов по
  шесть полей и сравнивает `M1: S1 ~ fCover`, `M2: S1 ~ theta_0_10` и
  `M3: S1 ~ theta_0_10 + fCover + theta*fCover`. Для 2 118 поле-дат робастная
  M3 имеет `R²_out=0.137` против `0.060` у M1 и `0.113` у M2; bootstrap по
  полям подтверждает положительный прирост M3–M1 (95% CI `0.035…0.128`) и
  M3–M2 (`0.009…0.042`). Осадки и поливы не являются предикторами, а служат
  только sensitivity-проверкой после исключения дат с `P0+I0>0`.
- Отчёты Sentinel-1 обновлены до schema version 2. В каждом варианте есть
  `observability_analysis`: pooled и внутриполевая Spearman-связь S1–theta,
  робастно стандартизованные аномалии, изменения между датами, sign-test и
  dry–wet AUC. Для VV/90 медианная внутриполевая Spearman равна `0.504`
  (bootstrap 95% `0.435…0.560`); Spearman изменений — `0.195`, а совпадение
  направления — `0.576` (95% `0.564…0.587`). Основным подтверждением всё ещё
  остаётся field-grouped прирост M3 относительно M1 и M2, а не эти
  внутриполевые диагностические показатели.
- Устойчивость результата проверена без смены дизайна: VH вместо VV при 65 см
  даёт для M3 `R²_out=0.267` (против 0.207 у M2), но 95% CI разности M3–M2
  включает ноль (`-0.0004…0.1103`). Вариант междурядья 90 см даёт те же
  результаты, что и 65 см в этой поставке. На 21 поле с положительным
  `FCOVER R² >= 0.70` VV-модель M3 сохраняет преимущество над M1 и M2:

## Следующие функции

1. Выбор конкретного контура, если НСПД возвращает неоднозначный объект.
2. Заполнить `data/ground_measurements.csv` реальными soil moisture/LAI/FCOVER и перезапустить analysis-пайплайн.
3. DEM: уклон, экспозиция, аккумуляция стока и водосборы.
4. Временные ряды и итоговая классификация зон водного режима.

Перед изменениями читать `README.md`, `ARCHITECTURE.md`, `DATA_MODEL.md`, `PIPELINES.md` и `DECISIONS.md`.
